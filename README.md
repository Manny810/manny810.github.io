# manny810.github.io

Public privacy policies and support pages for my apps, published with GitHub Pages at https://manny810.github.io/. Each app's code stays in its own private repo.

| App | Privacy policy | Support |
|---|---|---|
| Sweater Weather | https://manny810.github.io/sweater-weather/privacy-policy.html | https://manny810.github.io/sweater-weather/support.html |

## Adding or updating an app's pages

1. Copy the app's `docs/privacy-policy.md` and `docs/support.md` into a folder named after the app, for example `sweater-weather/`.
2. Add the app to `index.md` and to the table above.
3. Commit and push. GitHub Pages republishes the site within a few minutes.

These URLs are built into the apps and entered in App Store Connect, so don't rename or move a page after its app ships.
